# مدیریت فایل‌ها

## وظایف
1. ساخت پوشه‌های سازمانی (گزارش‌ها، داده‌ها، پشتیبان)
2. کپی فایل‌ها به مقصد مناسب
3. انتقال فایل‌های قدیمی به پوشه آرشیو
4. پاک‌سازی فایل‌های موقت
5. بررسی وجود فایل‌های تکراری

## ساختار پوشه پیشنهادی

## قوانین
- قبل از هر حذف، تأییدیه از مهندس بگیر.
- نام‌گذاری فایل‌ها با تاریخ: YYYY-MM-DD
- فایل‌های مهم را در پوشه پشتیبان کپی کن.
- از Copy-Item برای کپی و Move-Item برای انتقال استفاده کن.

## خروجی
گزارش کوتاه از عملیات انجام‌شده شامل:
- تعداد فایل‌های کپی/منتقل‌شده
- مسیرهای نهایی
- هرگونه خطا
