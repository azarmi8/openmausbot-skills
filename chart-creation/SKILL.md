# ساخت نمودار

## انواع نمودار مورد نیاز

### ۱. نمودار میله‌ای مقایسه ۷ و ۲۸ روزه
- نوع: BarChart
- محور X: کد طرح مخلوط
- محور Y: میانگین مقاومت (MPa)
- دو سری داده: ۷ روزه و ۲۸ روزه
- رنگ‌بندی: آبی و نارنجی

### ۲. نمودار پراکندگی بر حسب کد طرح مخلوط
- نوع: ScatterChart یا LineChart
- محور X: کد طرح مخلوط
- محور Y: مقاومت (MPa)
- نمایش کمینه، میانگین، بیشینه

### ۳. نمودار ستونی پشته‌ای وضعیت پذیرش
- نوع: StackedBarChart
- محور X: کد طرح مخلوط
- محور Y: تعداد نمونه
- سه سری: سبز (عالی)، زرد (خوب)، قرمز (بحرانی)

## کتابخانه
از openpyxl.chart استفاده کن (BarChart, LineChart, ScatterChart).

## نکات
- عنوان نمودار حتماً داشته باشد
- برچسب محورها فارسی یا انگلیسی واضح
- راهنما (Legend) فعال باشد
- ابعاد نمودار مناسب (width=15, height=10)
