# کنترل کیفیت خروجی

## چک‌لیست بررسی

### ۱. صحت محاسبات
- [ ] میانگین درست محاسبه شده
- [ ] انحراف معیار نمونه‌ای (n-1) درست
- [ ] انحراف معیار جامعه (n) درست
- [ ] ضریب تغییرات (CV) درست
- [ ] کمینه و بیشینه درست
- [ ] تبدیل واحد (kg/cm² → MPa) درست

### ۲. ملاک‌های پذیرش
- [ ] درصد مقاومت نسبت به رده محاسبه شده
- [ ] ملاک ۷ روزه اعمال شده (۵۶٪ و ۸۰٪)
- [ ] ملاک ۲۸ روزه اعمال شده (۹۰٪ و ۱۰۰٪)
- [ ] رنگ‌بندی وضعیت صحیح است

### ۳. انطباق با استانداردها
- [ ] ASTM C39 (مقاومت فشاری)
- [ ] ASTM C143 (اسلامپ)
- [ ] ASTM C31 (ساخت نمونه)
- [ ] استاندارد ملی ایران (نشریه ۱۲۰)

### ۴. ظاهر گزارش
- [ ] جدول‌بندی تمیز
- [ ] سربرگ کامل
- [ ] رنگ‌بندی وضعیت
- [ ] نمودارها با عنوان و برچسب
- [ ] امضا و تاریخ

## خروجی
گزارش کنترل کیفیت با ساختار زیر:

| بخش | وضعیت |
|------|-------|
| صحت محاسبات | ✅ / ❌ |
| ملاک‌های پذیرش | ✅ / ❌ |
| انطباق استاندارد | ✅ / ❌ |
| ظاهر گزارش | ✅ / ❌ |
| **وضعیت کلی** | ✅ تأیید / ❌ رد / ⚠️ اصلاح |

## قوانین
- اگر خطایی یافتید، دقیقاً مشخص کنید کجاست.
- راه اصلاح را به متخصص مربوطه بگویید.
- هرگز خروجی ناقص را تأیید نکنید.
